Rules

Contract details the UI respects.

01 / Auth

Bearer tokens and device keys

User endpoints send Authorization: Bearer <token>; ingestion sends X-Device-Key. A 401 triggers one refresh attempt before giving up.

02 / Values

Units and validation

N, P and K are dataset-scaled values ≥ 0; humidity 0–100; pH 0–14; rainfall ≥ 0. Soil moisture is stored and shown but is not a model input.

03 / Confidence

Low-confidence results

Below 0.60 the server replaces the crop name with a warning string. The UI detects it and shows advice to collect more data or consult an extension officer.

04 / Errors

Predictable error bodies

Errors use {"detail": ...}. Validation errors may be arrays of field messages; the UI renders either form.
